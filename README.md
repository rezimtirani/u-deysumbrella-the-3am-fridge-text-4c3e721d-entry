The one line a smart fridge texts its owner at 3am: the leftovers have unionized, and they want a better name than "probably still fine".

> 3am. Your leftovers just unionized. They want weekends off and a name that isn't 'probably still fine'.

## How it works

`main.py` (Python 3 standard library only) writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 140 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
